# 排水业务约定

服务面向污水处理厂、泵站和地下管网的运行人员。时间字段统一使用带时区的 ISO 8601 字符串，事件和测量记录应保留来源时间与接收时间，不能用展示层文字替代结构化状态。

健康接口只表示进程存活，不代表任何排水业务已经完成。需要落盘的数据应使用运行时配置指定的位置，测试不得依赖主机上的隐藏状态。

抢修调度域在 `reference/dispatch/` 的参考数据与 `src/dispatch/` 模块内实现，约定：

- 每条输入同时保留 `occurredAt`（来源时间）与 `receivedAt`（接收时间）；离线补传以发生时间接入。
- 同一影响范围（拓扑合并组）只维护一张在途工单；已进入 onsite/working 的工单不受普通合并与改派影响。
- 危险等级、资质、备件、班次、可通行路线是派工闸门；命中“先隔离”规则时未登记隔离不得派工。
- 道路封闭/限行与超时提醒都属于处置事实，必须落 journal 并可在重启后重放，不能只存在内存或展示层。
- 派工冲突用版本号（乐观锁）暴露，禁止后写静默覆盖先写。
